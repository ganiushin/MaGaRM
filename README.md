# MaGaRM

Шестиосевая рука с захватом и камерой на запястье под сбор данных и запуск VLA-моделей. Все детали корпуса печатные. Моторы со встроенными драйверами и энкодерами, управляются по одной шине CAN в MIT-режиме: можно задавать и жёсткость, и мягкость суставов, читать моменты.

3D-модель всей руки открывается в браузере: `cd viewer && python3 -m http.server`, затем http://localhost:8000.

| Сустав | Мотор | Ход |
|---|---|---|
| J1 основание | Damiao DM-JH17-101 (волновой редуктор) | ±160° |
| J2 плечо | Damiao DM-JH17-101 (волновой редуктор) | 0…200° |
| J3 локоть | Damiao DM-J4340P | −230…−3.5° |
| J4 наклон запястья | Damiao DM-J4340 | −50…+90° |
| J5, J6 запястье | RobStride EL05 | ±90° |
| Захват | Damiao DM-H3510 | ±90° (кривошип) |

Питание 24 В. Масса около 4.3 кг, из них моторы — 3.3 кг. Моторы J1 и J2 по 985 г стоят в основании и в конце плеча у оси J2, на осях своих суставов, и руку не нагружают.

## Что где

| Папка | Содержимое |
|---|---|
| [`cad/parts/`](cad/parts) | все 24 печатные детали: STL для печати и STEP для правок, `parts.json` |
| [`cad/scripts/`](cad/scripts) | скрипты, которые строят детали, URDF и 3D-модель из исходной сборки (build123d) |
| [`cad/motors/`](cad/motors) | официальные STEP-модели моторов Damiao |
| [`urdf/`](urdf) | `magarm.urdf` с сетками, массами и инерциями из CAD |
| [`sim/`](sim) | модель для MuJoCo: рука с настоящим механизмом захвата, сцена, демо pick-and-place |
| [`software/`](software) | пакет `magarm` на Python: драйверы Damiao и RobStride, управление рукой, тесты |
| [`viewer/`](viewer) | 3D-просмотрщик (three.js) |
| [`cad/fonts/`](cad/fonts) | шрифт логотипа Russo One (SIL OFL 1.1) |
| [`docs/`](docs) | документация |

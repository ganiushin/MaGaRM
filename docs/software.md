# Софт

`software/magarm` — пакет на Python, который управляет всей рукой по одной CAN-шине:
- `damiao.py` — протокол Damiao в MIT-режиме: включение, выключение, ноль, команда (p, v, kp, kd, τ), обратная связь, чтение PMAX/VMAX/TMAX из мотора;
- `robstride.py` — протокол RobStride для EL05: режим работы, включение, стоп, ноль, команда управления движением, обратная связь;
- `arm.py` — класс `Arm`: приём кадров в отдельном потоке, углы суставов в системе URDF, команды с ограничением по пределам URDF, плавное перемещение `move_to`, пассивный режим для обучения рукой;
- `config.py` — таблица суставов: протокол, ID, направление, смещение нуля, пределы, коэффициенты по умолчанию.

## Установка

```bash
cd software
pip install -e .            # python-can, numpy
pip install -e ".[test]" && pytest     # тесты кадров и проверка Arm на виртуальной шине, без железа
```

## Первый запуск

1. **Моторы.** Настройте ID по [motors_check.md](motors_check.md), поднимите `can0` по [electrical.md](electrical.md).
2. **Проверка связи.** Запустите `python tools/scan.py`: в строке должны быть все 7 суставов с углами. Моторы при этом не включены, руку можно двигать рукой.
3. **Направления.** Поверните каждый сустав рукой в положительную сторону оси из URDF. Угол `q` в `scan.py` должен расти. Если он уменьшается, поставьте этому суставу `direction=-1.0` в `config.py`.
4. **Нули.** Положите руку в позу CAD, это q = 0, как в просмотрщике:
   - плечо лежит горизонтально вперёд;
   - предплечье сложено назад поверх плеча до упора барабана J4 в барабан мотора J2;
   - запястье и захват вытянуты вдоль предплечья, разъём захвата внизу.

   После этого запустите `python tools/set_zero.py all`. У J3 в этой позе угол −3.5°: полностью сложиться ему не даёт барабан, и это уже учтено в `config.py` (`offset` у joint3). Если поза получилась неточной, впишите текущий угол мотора в `offset` нужного сустава.
5. **Пробное движение:**

```python
from magarm import Arm
with Arm() as arm:
    arm.enable()
    arm.move_to([0, 0.8, -1.4, 0.3, 0, 0, 0], duration=4.0)   # медленно, с малыми kp из config.py
    print(arm.q())
    arm.disable()
```

Перед первым включением держите руку у кнопки аварийного отключения.

## Модель (URDF)

`urdf/magarm.urdf` сгенерирован из CAD скриптом `cad/scripts/make_urdf.py`:
- кинематика и пределы суставов;
- сетки звеньев;
- массы и инерции: печать считается PLA при ~55 % заполнения, моторы по паспортным массам.

Нулевая поза URDF совпадает с позой CAD. Пределы учитывают проверки столкновений:
- J2 ограничен 200°: на 207° балка плеча упирается в пол вилки;
- J3 не доходит 3.5° до полного складывания;
- J4 вверх только до 50°.

Модель подходит для MoveIt, Pinocchio (гравитационная компенсация через `tau` в `Arm.command`) и симуляторов (MuJoCo, Isaac).

Для VLA рука отдаёт углы через `Arm.q()` и принимает целевые углы через `Arm.command()`, а камеру читайте через OpenCV. Сбор демонстраций удобен в пассивном режиме `arm.passive()`: руку водят рукой, углы пишутся с нужной частотой. J1 и J2 на волновых редукторах 101:1 рукой не проворачиваются, поэтому для них нужна ведущая рука или другое телеуправление.

## Симуляция (MuJoCo)

`sim/` — модель руки для MuJoCo:
- `magarm.xml` — рука: кинематика, массы и сетки из URDF, сервоприводы как в MIT-режиме (kp, kd из `config.py`, предел момента из URDF), датчики моментов и TCP, камера на запястье `wrist`;
- захват смоделирован настоящим механизмом: кривошип, две тяги, губки на рельсе (замкнутая цепь);
- `scene.xml` — стол, кубик, банка, тарелка, внешняя камера `front`;
- `demo.py` — пример: рука по IK берёт кубик и ставит на тарелку, печатает пиковые моменты моторов и сохраняет кадры с камер в `sim/out/`.

```bash
pip install mujoco pillow
python -m mujoco.viewer --mjcf=sim/scene.xml   # просмотр; суставы двигаются ползунками во вкладке Control
python sim/demo.py                              # демо без окна
mjpython sim/demo.py --view                     # демо в окне (на macOS нужен mjpython из пакета mujoco)
```

Рабочая зона — сторона −X: туда смотрит захват в позе CAD, и там J1 (±160°) поворачивается в обе стороны полностью.
Рука не сталкивается сама с собой в симуляции, только с предметами сцены. Коллизии считаются по выпуклым оболочкам сеток.
Инерция роторов (`ARMATURE` в `make_mjcf.py`) и сухое трение волновых редукторов J1 и J2 (`FRICTION`) — оценки, их стоит заменить на измеренные.

`magarm.xml` генерируется скриптом `python sim/make_mjcf.py` из URDF и `sim/gripper.json`. Отдельные детали захвата (`sim/assets/`, `sim/gripper.json`) выгружает `cad/scripts/make_urdf.py` вместе с URDF, см. `build_all.sh`.
